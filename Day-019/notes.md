# Day 019 - Advanced Python

## Iterator

An iterator is used to access elements one by one.

Functions:

iter()

next()

---

## Generator

Generators use the yield keyword.

Advantages:

- Saves memory
- Faster than returning large lists
- Lazy evaluation

Example:

yield value

---

## Decorator

A decorator adds extra functionality to an existing function.

Syntax:

@decorator

---

## *args

Accepts multiple positional arguments.

Example:

def add(*numbers):

---

## **kwargs

Accepts multiple keyword arguments.

Example:

def student(**details):
