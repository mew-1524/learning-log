## Topics Learned

- for loop
- while loop
- range()
- break
- continue
- pass

## Key Points

- for loop is used when the number of iterations is known.
- while loop runs until a condition becomes False.
- break exits the loop.
- continue skips one iteration.
- pass is a placeholder.
