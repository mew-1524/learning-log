# Day 016 - Object-Oriented Programming (OOP)

## What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm that organizes code using classes and objects.

---

## What is a Class?

A class is a blueprint for creating objects.

Example:

class Student:
    pass

---

## What is an Object?

An object is an instance of a class.

Example:

student = Student()

---

## Constructor (__init__)

A constructor is automatically called when an object is created.

Example:

def __init__(self, name):
    self.name = name

---

## Instance Variables

Variables that belong to an object.

Example:

self.name
self.age

---

## Instance Methods

Functions inside a class that work with object data.

Example:

def display(self):
    print(self.name)

---

## Advantages of OOP

- Code Reusability
- Better Organization
- Easy Maintenance
- Real-world Modeling
- Modular Programming
