# Day 009 - Dictionaries

## What is a Dictionary?

A dictionary stores data as key-value pairs.

Example:

student = {
    "name": "Aadesh",
    "age": 17
}

---

## Properties

- Uses {}
- Stores key-value pairs
- Mutable
- Keys must be unique
- Values can be duplicated

---

## Dictionary Methods

keys()

Returns all keys.

values()

Returns all values.

items()

Returns key-value pairs.

get()

Returns value of a key.

pop()

Removes a key.

update()

Updates dictionary.

---

## Looping

for key, value in dictionary.items():
    print(key, value)

---

## Difference

List
- Ordered
- Uses indexes

Dictionary
- Uses keys
- Faster searching
