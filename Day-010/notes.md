# Day 010 - Sets in Python

## What is a Set?

A set is an unordered collection of unique elements.

Example:

fruits = {"Apple", "Banana", "Mango"}

---

## Properties

- Uses {}
- Stores only unique values
- Removes duplicate values automatically
- Unordered (no indexing)
- Mutable (can add or remove elements)

---

## Common Methods

add()

Adds a new element.

remove()

Removes an element.

discard()

Removes an element without causing an error if it doesn't exist.

clear()

Removes all elements.

copy()

Creates a copy of the set.

---

## Set Operations

Union

set1 | set2

Intersection

set1 & set2

Difference

set1 - set2

Symmetric Difference

set1 ^ set2
