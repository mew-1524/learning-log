# Day 33 - Matplotlib Data Visualization

## Matplotlib

Matplotlib is a Python library used for
creating data visualizations.

Import:

import matplotlib.pyplot as plt

## Line Chart

plt.plot(x, y)

Used for trends over time.

## Bar Chart

plt.bar(x, y)

Used to compare categories.

## Horizontal Bar

plt.barh(x, y)

## Pie Chart

plt.pie(values, labels=labels)

Used to show parts of a whole.

## Histogram

plt.hist(data)

Used to show distribution.

## Scatter Plot

plt.scatter(x, y)

Used to show relationships between two variables.

## Labels

plt.title()
plt.xlabel()
plt.ylabel()

## Legend

plt.legend()

## Display

plt.show()

## Save Graph

plt.savefig("graph.png")

## Important

Time → Line
Compare → Bar
Distribution → Histogram
Parts of whole → Pie
Relationship → Scatter
