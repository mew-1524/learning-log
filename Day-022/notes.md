# Day 022 - NumPy Part 2

## Array Creation

NumPy provides functions to create arrays easily.

---

## np.zeros()

Creates an array filled with zeros.

Example:

np.zeros(5)

---

## np.ones()

Creates an array filled with ones.

Example:

np.ones(5)

---

## np.arange()

Creates numbers within a range.

Example:

np.arange(1, 11)

It can also use a step:

np.arange(0, 21, 5)

---

## np.linspace()

Creates evenly spaced numbers.

Example:

np.linspace(0, 10, 5)

---

## reshape()

Changes the shape of an array.

Example:

arr.reshape(3, 4)

The total number of elements must remain the same.

---

## Random Numbers

np.random.randint()

Generates random integers.

Example:

np.random.randint(1, 101, 10)

---

np.random.rand()

Generates random decimal values between 0 and 1.
