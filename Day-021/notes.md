# Day 021 - NumPy Part 1

## What is NumPy?

NumPy (Numerical Python) is a Python library used for numerical computing.

---

## Advantages

- Faster than Python Lists
- Less Memory Usage
- Easy Mathematical Operations
- Used in AI, ML, Data Science

---

## Creating Arrays

np.array()

Example:

arr = np.array([1,2,3])

---

## Array Attributes

shape

Returns rows and columns.

size

Returns total number of elements.

ndim

Returns dimensions.

dtype

Returns data type.

---

## Indexing

arr[0]

arr[-1]

---

## Slicing

arr[1:4]
